【产品简介】
本工作台是专为酒店固装/活动家具定制、建筑室内深化施工图打造的生产级双模式翻译系统。
彻底解决 CAD 图纸 SHX 单线字识别致盲、引出线与多层旋转坐标错位、乱码重影、机翻不专业等行业顽疾。
支持局域网全员免安装浏览器共享，团队协作零门槛。

────────────────────────────────────────────────────────────────────────────────
【一键启动方式】
────────────────────────────────────────────────────────────────────────────────
1. 双击桌面或本目录下的：【启动翻译工作台.bat】
2. 黑窗口会自动加载环境并自动在默认浏览器打开翻译工作台：
   - 本机浏览器访问：http://127.0.0.1:7860
   - 局域网同事访问：http://你的局域网IP:7860 (同一Wi-Fi/办公室网络下直接打开即可，具体 IP 见工作台「设置 → 局域网共享」)
3. 提示：使用期间保持后台黑窗口开启，用完关闭黑窗口即可。

────────────────────────────────────────────────────────────────────────────────
【功能模块详解】
────────────────────────────────────────────────────────────────────────────────

▶ 模块一：📐 翻译工作台（首页主界面）
  · 适用场景：AutoCAD 导出的 PDF 施工图、家具节点大样图、五金标号图、天花反射图，
    以及产品目录画册、五金规格书、商务合同等常规文档（在"翻译设置"中切换"说明书画册"模式）。
  · 核心特色：
    1. CAD 图纸模式：视觉大模型直接读图翻译（不再依赖 OCR 识别文字的准确度），
       配合算力服务器 PaddleOCR 检测文字位置，英文/越南语/泰文等任何语言通吃，
       1:1 原位擦除回填，100% 保护图纸原有几何图线，旋转标注方向自动跟随原图；
    2. 说明书画册模式：BabelDoc 流式排版引擎，支持纯中文译文版 / 中英双语对照版；
    3. 页面范围灵活抽翻：填 "18, 22-25, 81" 只翻这几页，留空翻全本；
    4. 翻译引擎随意切换：设置页可接入任意 OpenAI 兼容的多模态模型服务
       （DeepSeek / 智谱 / 通义 / 硅基流动 / 本地模型均可），接入时自动验证识图能力，
       纯文本模型无法启用；切换不影响进行中的任务，费用按引擎分别记账；
    5. 实时译文预览：基于 PDF.js 的多页预览，支持翻页、缩放、全屏，翻译完成后即时查看；
    6. 一键下载：状态栏"下载译文 PDF"直接保存交付。

▶ 模块二：📚 术语库（企业标准词库）
  · 左侧按分类筛选（家具设计 / 建筑设计 / 机电照明 / 五金材料等，可自定义分类）；
  · 词条字段：英文原文、中文译文、分类、使用次数、更新时间；
  · 使用次数自动累计：翻译命中的词条自动 +1，高频术语一目了然；
  · 支持 新建/编辑/删除/批量删除，导入（JSON/CSV）/导出（JSON/CSV）；
  · 大模型翻译时强制优先使用公司设定的标准术语。

▶ 模块三：📁 项目记录
  · 每次翻译任务（成功或失败）自动持久化到本地 task_history.json，重启不丢；
  · 支持按状态筛选（全部/进行中/已完成/失败）与按项目名/文件名搜索；
  · 已完成的项目可一键"查看"（回到工作台预览成果）或"下载"。

▶ 模块四：⚙️ 设置（右上角齿轮）
  · 翻译偏好：默认引擎与默认目标语言，保存在本机浏览器，工作台自动应用；
  · API 密钥与账单：查看实时余额、历史任务数与累计消耗，修改并验证 API 密钥
    （密钥自动保存到本目录 config.json，向外部分享代码文件时请删除该文件）；
  · 局域网共享：展示并复制局域网访问地址，同事免安装直接使用。

【输出文件归档目录】
────────────────────────────────────────────────────────────────────────────────
所有翻译生成的 PDF 均自动归档在：
  本程序目录下的 output\ 文件夹（与启动脚本同级）
  - CAD 图纸输出：[原文件名]_专业中文版.pdf（含首页预览图 _preview.png）
  - 文档输出：[原文件名].no_watermark.zh.mono.pdf / dual.pdf
